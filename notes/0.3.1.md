## Changed
- **The compiler's npm package is `extended-mark`.** npm doesn't allow the name `xtmd` (it is too like `xtend` and other packages), so `npm i -g extended-mark` installs the `xtmd` command, `import { build, check } from "extended-mark"` is its API, and `extended-mark/vite` its Vite plugin. The command, the crate (`cargo install xtmd`) and the one-line installers are unchanged. 0.3.0's `extended-mark` and `@extended-mark/next` on npm can't be installed, since they ask for `xtmd`; use 0.3.1.
## Fixed
- **0.3 reaches every registry.** 0.3.0 stopped at npm; 0.3.1 is the first release of 0.3 on crates.io, the VS Code Marketplace and Open VSX, and every npm package is at 0.3.1.
