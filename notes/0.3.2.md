## Changed
- **Published from the repository, with provenance.** Each npm package and crate comes straight from Extended Mark's release workflow on GitHub, through the registries' trusted publishing: no token publishes them. On npm each version carries a provenance statement linking it to the workflow run and the commit it was built from, which `npm audit signatures` checks.
