A TREE MOVED BY WHAT EACH RELEASE UNDERSTANDS  compiler/xtmd/src/migrate/pipeline.rs
`xtmd migrate <tree>`, for a tree written for the release right before this one
(compiler/xtmd/src/cli/migrate_rir.rs route(): any other release is refused by name; xtmd.toml saying
none is taken as that one, out loud).
1. readers/: the release before's front end, built into the command (previous(), never the wasm build),
   gives each file's resolved IR and each document's Markdown. readers::This reads this release's.
2. rir/: ONE step (STEP) from that release's rir to this one's, over the JSON, by names and types; it
   runs even when the rir version stays. Input fits the old schema (schemas/rir-history, copied into
   src/migrate/rir), output NOW's. It asks (Asked::ask, answered in --answers as [steps] "id" = "x")
   and leaves a TODO above what no answer can move (Asked::todo).
3. decompile prints every file; compile_all compiles each back to its resolved IR (and Markdown).
4. Round trip: pipeline::written(the step's) must equal written(the printed file's): spans, sha256 and
   expression types aside, every name's target kept. Markdown changed: a warning, never a refusal.
5. Refused or a question open: nothing written. Else every file, beside then renamed; TODOs: exit 3.
Until rir::READY, a 0.3.2 tree still takes compiler/xtmd/src/cli/migrate.rs's text steps (releases.rs).
compiler/xtmd/tests/migrate_pipeline.rs runs a made-up release before, rir 1 with `words` for `prose`;
compiler/xtmd/tests/migrate_032.rs runs every 0.3.2 file of checks/migrate-0.3 against expected.tsv.
