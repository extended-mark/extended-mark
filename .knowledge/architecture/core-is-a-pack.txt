CORE IS A PACK
core/ is Extended Mark, imported by every file. The compiler knows only syntax and what is `extern`.
Interfaces join a type to the syntax: literal (text literals), shown (holes), same and ordered
(comparisons), numeric and scaled (arithmetic).

Exceptions, on purpose: prose has to become something, so the checker writes calls of core's blocks
and words (compiler/check/src/view.rs, compiler/check/src/rich.rs); the runtimes know core/page,
and the layout core/plane and core/spot.
