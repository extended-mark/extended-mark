THE COMMAND'S RULES
One spelling a flag; --format json, --out and --help everywhere. An unknown flag warns, and a run
that would write files then writes nothing. A dropped flag fails and says what replaced it.
Exit codes: 0 done, 1 something is wrong, 2 usage. Questions are all listed, then asked; --yes.
Help is compiler/cli/src/help.rs, flags compiler/cli/src/flags.rs: change both with the command.
